# Rasa Gated Phase Checklist

This is the codebase checklist. It uses a strict definition of complete: a workstream is only checked when its production-relevant behavior is implemented, tested, and founder-approved. A prototype screen is not a completed product capability.

The public-facing version is available at `/build` in the web app.
